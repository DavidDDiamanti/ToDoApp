# Todo App v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add optional due times, drag-and-drop reordering and nesting with a keyboard fallback, and a visible message for expired sign-in links, on branch `feat/todo-app` so PR #1 carries them.

**Architecture:** Unchanged. Pure domain functions produce patches; the Zustand store applies them and marks rows dirty; the sync engine flushes whole rows. Two new pure modules (`src/domain/place.ts`, `src/dnd/hitTest.ts`), one tiny drag store (`src/dnd/dragStore.ts`), one hook (`src/dnd/useDragReorder.ts`), one parser (`src/lib/authUrlError.ts`).

**Tech Stack:** as v1 (React 19, TypeScript strict, Zustand 5, Vitest 5, jsdom 30, RTL 16). No new dependencies.

Spec: `docs/superpowers/specs/2026-09-10-todo-app-design.md` section 12.

## Global Constraints

All v1 constraints from `docs/superpowers/plans/2026-09-10-todo-app.md` still apply (strict TS, no `any`, no `as unknown as`, no barrels, `useMemo` tree, ternaries, 44 px targets, `Date.parse` for timestamps, commit trailer, never commit to `main`). Additions:

- `due_time` is `HH:MM` (24-hour) or `null`; never non-null while `due_date` is `null`.
- Overdue: `isOverdue(todo, now: Date)`. No time: `due_date < todayISO(now)`. With time: local instant `< now`.
- Drag listeners (`pointermove`, `pointerup`, `pointercancel`, `keydown`) are added to `window` only inside `useDragReorder` on pointer down and removed on finish; the hook's effect cleanup also removes them. `useSync` stays the only site for `online`, `visibilitychange` and the interval.
- Pointer-move work updates refs and a deduplicated drag store; it must not set React state on every move. The drop indicator is a `data-drop` attribute on exactly one `li`.
- jsdom has zero-size rects: every geometry consumer takes an injectable `getRect` and tests pass a fake.
- Placement indices are into the target bucket **excluding** the moved item.
- Test file for a component test is colocated; the `styles.x === 'x'` non-scoped CSS module rule holds in tests.
- Test command `npm test` (vitest run), types `npm run typecheck`. Both must pass before each commit.
- Never use bare `git stash` or `git stash pop`.

Task order: 1 → 2 → 3 → 4 (due time), 5 → 6 → 7 → 8 (placement and drag), 9 (auth, independent), 10 (README, last).

### Task 5: placement domain; delete `moveTodo`

**Files:** create `src/domain/place.ts`, `src/domain/place.test.ts`; modify `src/domain/ops.ts`, `src/domain/ops.test.ts`, `src/store/actions.ts`, `src/store/actions.test.ts`.

**Interfaces (`src/domain/place.ts`):**
```ts
export interface Placement { parentId: string | null; index: number } // index into target bucket WITHOUT the moved item
export type DropZone = 'before' | 'inside' | 'after';
export type MoveKey = 'up' | 'down' | 'left' | 'right';
export const MIN_GAP = 1e-6;
export function sortOrderBetween(prev: Todo | undefined, next: Todo | undefined): number
export function parentKeyOf(map: ChildrenMap, id: string): string | null | undefined // map key; undefined if absent
export function canPlace(map: ChildrenMap, id: string, parentId: string | null): boolean // false for self or descendant
export function placeTodo(byId: Record<string, Todo>, map: ChildrenMap, id: string, target: Placement, now: string): Patch[]
export function dropToPlacement(map: ChildrenMap, draggedId: string, targetId: string, zone: DropZone): Placement | null
export function keyMovePlacement(map: ChildrenMap, id: string, key: MoveKey): Placement | null
export function describePlacement(byId: Record<string, Todo>, map: ChildrenMap, id: string, target: Placement): string
```
Behaviour: `sortOrderBetween`: none → 0; only next → `next.sort_order - 1`; only prev → `prev.sort_order + 1`; both → midpoint. `placeTodo`: `[]` for unknown id, `!canPlace`, or already at that position; `siblings = bucket(parentId)` minus the item, index clamped to `[0, siblings.length]`; `prev = siblings[index-1]`, `next = siblings[index]`; if both exist and `next.sort_order - prev.sort_order < MIN_GAP` → renumber `[...siblings.slice(0, index), item, ...siblings.slice(index)]` to `0..n`, patching the item always and every sibling whose `sort_order` changes; else one patch `{ id, parent_id: parentId, sort_order: sortOrderBetween(prev, next), updated_at: now }`. `dropToPlacement`: null if target is the dragged item or its descendant; `'inside'` → `{ parentId: targetId, index: bucket(targetId) minus dragged .length }`; `'before'|'after'` → `parentId = parentKeyOf(map, targetId)` (undefined → null), index = position of target in that bucket minus dragged, plus one for after. `keyMovePlacement` on full buckets: up → `i-1` (null at 0), down → `i+1` (null at end), right → previous sibling `p` → `{ parentId: p.id, index: bucket(p.id).length }` (null when first), left → parent `P` → `{ parentId: parentKeyOf(map, P), index: indexOf(P) + 1 }` (null at root). `describePlacement`: `Moved ${title} under ${parentTitle}, position ${index + 1} of ${n}` or `Moved ${title} to the top level, position ${index + 1} of ${n}` where `n` = bucket minus item, plus one.

`actions.moveTodoTo(id: string, target: Placement): void` → `applyPatches(placeTodo(...))`. Delete `moveTodo` from `ops.ts` and its describe block from `ops.test.ts`; drop now-unused imports.
